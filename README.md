# 🏰 MemorizationDungeonCrawler  
### Built for the 2025 Hackathon  
A spooky-fun dungeon crawler that tests your memory, your reflexes, and your ability to avoid being bonked by pixel monsters.

## 🧠 Features
- Procedurally generated dungeons
- Fight enemies and earn keys
- Data driven JSON flashcards allow you to use any set of flashcards you want

---

## 🎮 Controls
- **WASD** → walk around like you mean it  
- **Mouse** → look around suspiciously
- **ESC** → panic pause
